## Keeping both versions useful / 维护说明

When changing a command, environment variable, requirement, or limitation, update its English and Chinese guides together. Preserve command names, configuration keys, file paths, and the app's exact button labels in translations. Screenshots show the real Chinese UI; captions should explain it rather than imply the UI has been translated.

修改命令、环境变量、运行前提或限制时，请同时更新中英文版本。翻译时保留命令名称、配置键、文件路径及界面按钮的原始标签。截图来自真实中文界面，说明文字应帮助读者理解，不应让读者误以为应用已提供英文界面。
