# Calibre

![](https://raw.githubusercontent.com/kovidgoyal/calibre/master/resources/images/lt.png)

calibre 是一个电子书管理工具。它可以查看、转换、编辑和分类所有主要格式的电子书。它还可以与电子书阅读设备进行通信。它可以连接互联网并为您的书籍获取元数据。它可以下载报纸并将其转换为电子书，方便阅读。calibre 是跨平台的，可以在 Linux、Windows 和 macOS 上运行。

## 开发

设置 calibre 开发环境的步骤如下：

1. 安装必要的依赖项。
2. 克隆 calibre 源代码仓库。
3. 配置开发环境。
4. 编译和运行 calibre。

当前版本的 calibre 源代码 tarball 可以在 [这里](https://calibre-ebook.com/dist/src) 下载。
